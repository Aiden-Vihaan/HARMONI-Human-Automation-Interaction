# HARMONI — Research Positioning

## Project Identity

HARMONI is an independent Human Factors and HCI research project.

It is designed to stand on its own as an academic and technical portfolio project.

The project is not affiliated with, commissioned by, or designed specifically for any university, company, laboratory, or institution.

---

# Core Research Statement

> HARMONI investigates how humans understand and interact with intelligent automation when system capabilities, limitations, and required actions must be communicated clearly and effectively.

---

# Research Position

HARMONI sits at the intersection of:

- Human Factors
- Human–Computer Interaction
- Human–Automation Interaction
- UX Research
- Automated Driving
- Explainable Automation
- Experimental Research
- Software Engineering
- Data Analysis

---

# What HARMONI Is

HARMONI is:

- A Human Factors research project
- An HCI project
- An experimental study
- An interactive software prototype
- A data-driven investigation
- A research communication project

---

# What HARMONI Is Not

HARMONI is not:

- A production autonomous-driving system
- A commercial automotive product
- A new autonomous-driving algorithm
- A computer-vision project
- A generic Figma case study
- A generic AI chatbot project
- A university-specific demonstration project

---

# Difference From a Conventional UX Project

A conventional UX portfolio project may focus primarily on:

- Visual design
- User flows
- Usability
- User satisfaction

HARMONI additionally investigates:

- Human behaviour
- Situation awareness
- Trust
- Workload
- Automation transparency
- Intervention
- Behavioural outcomes

The interface therefore functions as an experimental variable.

---

# Difference From a Conventional Software Project

A conventional software project generally emphasizes:

- Features
- Functionality
- Architecture
- Performance

HARMONI uses software as an experimental research instrument.

The simulation exists to:

1. Create controlled scenarios.
2. Present experimental conditions.
3. Record participant behaviour.
4. Generate structured data.
5. Enable empirical evaluation.

---

# Difference From a Generic AI Project

HARMONI does not primarily focus on improving an AI model.

Instead, it investigates the human side of intelligent systems.

The central question is:

> How should humans interact with systems that can perform tasks or make decisions on their behalf?
