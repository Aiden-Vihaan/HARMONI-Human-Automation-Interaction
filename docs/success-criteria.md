# Quality Standard

HARMONI will be considered successful not merely when the software works, but when the project demonstrates a coherent chain:

**Research Problem**
→ **Literature**
→ **Research Gap**
→ **Research Question**
→ **Hypothesis**
→ **Human Factors Design**
→ **Experimental Prototype**
→ **Participant Data**
→ **Analysis**
→ **Evidence**
→ **Human Factors Implications**

The project should not claim conclusions that are unsupported by the collected evidence.
