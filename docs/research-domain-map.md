# HARMONI — Research Domain Map

## Purpose

This document defines the academic and technical domains that form the foundation of HARMONI.

The project is interdisciplinary and combines Human Factors, HCI, automated systems, experimental research, and data analysis.

---

# 1. Human Factors

Human Factors examines the interaction between humans and the systems, technologies, environments, and tasks in which they operate.

## Relevance to HARMONI

HARMONI investigates how characteristics of an automated system's interface influence:

- Understanding
- Decision-making
- Workload
- Trust
- Intervention
- Behaviour

---

# 2. Human–Computer Interaction

HCI studies how people interact with interactive computing systems and how those systems can be designed and evaluated around human needs and capabilities.

## Relevance

The HARMONI interface is the primary communication channel between the automated system and the human operator.

---

# 3. Human–Automation Interaction

Human–Automation Interaction investigates how humans interact with systems that perform tasks with varying levels of automation.

## Relevance

This is the central domain of HARMONI.

The project investigates:

- Monitoring
- Understanding
- Reliance
- Trust
- Intervention
- Automation limitations
- System transparency

---

# 4. Situation Awareness

Situation awareness concerns a person's understanding of relevant elements of a dynamic environment and their implications for action.

## Relevance

HARMONI investigates whether users understand:

- The current automation state
- Relevant environmental events
- System capabilities
- System limitations
- Required human actions

---

# 5. Trust in Automation

Trust influences whether and how humans rely on automated systems.

## Relevance

HARMONI investigates whether additional system transparency affects:

- Trust
- Confidence
- Reliance
- Intervention decisions

The project does not assume that increasing trust is automatically beneficial.

---

# 6. Appropriate Reliance

Appropriate reliance concerns using automation when it is suitable while recognizing situations where human intervention is required.

## Relevance

HARMONI considers appropriate reliance as a more meaningful Human Factors objective than simply maximizing user trust.

---

# 7. Mental Workload

Mental workload concerns the cognitive demands experienced while performing a task.

## Relevance

The project investigates whether contextual information:

- Reduces uncertainty
- Improves understanding
- Increases cognitive demand
- Creates information overload
- Changes perceived workload

---

# 8. Automation Transparency

Automation transparency concerns how clearly an automated system communicates information about its:

- Current state
- Capabilities
- Limitations
- Actions
- Intentions

## Relevance

Transparency is one of the central design concepts investigated in HARMONI.

---

# 9. Explainable Automation

Explainable automation concerns mechanisms through which automated systems communicate information that helps humans understand system behaviour, state, decisions, or limitations.

## Relevance

HARMONI investigates contextual explanations as one possible approach to improving human understanding of automation.

---

# 10. Automated Driving

Automated driving provides the experimental domain.

It combines:

- Complex automation
- Human monitoring
- Dynamic environments
- Time-critical intervention
- System limitations
- Safety-related decisions

---

# 11. Experimental UX Research

HARMONI combines interface design with experimental evaluation.

Instead of evaluating only:

> "Do users like this interface?"

the project investigates:

> "Does this interface change measurable human behaviour and perception?"

---

# 12. Software Engineering

Software serves as the experimental research instrument.

The simulation will provide:

- Controlled scenarios
- Repeatable conditions
- Interface manipulation
- Event timing
- Participant interaction
- Data collection

---

# 13. Data Science

Experimental data will be analysed using quantitative methods.

Potential measures include:

- Reaction time
- Decision accuracy
- Error rate
- Situation awareness
- Trust
- Workload
- Confidence

---
