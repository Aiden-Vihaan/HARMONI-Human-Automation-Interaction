---

# 1. Study Title

HARMONI:

Human–Automation Communication Richness and Intervention

---

# 2. Research Question

How does the richness of automation communication during a critical system limitation affect human Situation Awareness, mental workload, and intervention performance?

---

# 3. Study Objective

Determine whether increasing automation communication richness:

1. Improves Situation Awareness.
2. Changes mental workload.
3. Improves or impairs intervention performance.
4. Influences trust/reliance.

---

# 4. Experimental Design

Within-subject controlled experiment.

Each participant experiences all communication conditions.

---

# 5. Independent Variable

Communication Richness

Four conditions:

### C1 — Minimal

System state + action.

### C2 — Context

System state + environmental context + action.

### C3 — Explanation

System state + environmental context + reason + action.

### C4 — Explanation + Action Guidance

System state + environmental context + reason + explicit urgent action.

---

# 6. Primary Outcomes

## Situation Awareness

Measure participants' understanding of:

- What happened?
- What is the current system state?
- What is likely to happen next?

---

## Mental Workload

Measure perceived workload using the selected validated instrument.

Current candidate:

NASA-TLX.

---

# 7. Secondary Outcomes

- Reaction time
- Decision accuracy
- Appropriate intervention
- Missed intervention
- Unnecessary intervention
- Trust
- Confidence
- Reliance

---

# 8. Scenario

The participant interacts with a simulated automated system.

Initial state:

AUTOMATION ACTIVE
