# HARMONI — Literature Matrix

## Purpose

This literature matrix is used to systematically review existing academic research relevant to HARMONI.

The objective is to understand existing theories, methodologies, measurements, findings, and limitations before finalizing the research question and experimental design.

The matrix will be continuously updated throughout the research phase.

---

# Research Areas

The initial literature review focuses on:

1. Human–Automation Interaction
2. Human Factors
3. Automated Driving
4. Situation Awareness
5. Trust in Automation
6. Appropriate Reliance
7. Mental Workload
8. Automation Transparency
9. Explainable Automation
10. Human–Machine Interface Design
11. Takeover / Intervention Behaviour
12. Explainable AI

# Paper Evaluation Template

Each paper should be evaluated using the following structure.

| Field | Description |
|---|---|
| Paper ID | Unique identifier |
| Title | Full paper title |
| Authors | Authors |
| Year | Publication year |
| Venue | Journal / conference |
| DOI | DOI if available |
| URL | Source URL |
| Research Area | Main research domain |
| Research Question | What did the researchers investigate? |
| Participants | Participant characteristics and sample size |
| Experimental Context | Environment or task |
| Method | Experimental / survey / review / qualitative / mixed |
| Independent Variables | Variables manipulated or compared |
| Dependent Variables | Variables measured |
| Measures | Scales, behavioural metrics, physiological measures, etc. |
| Main Findings | Key results |
| Limitations | Important limitations |
| Future Work | Suggested future research |
| HARMONI Relevance | Why the paper matters to HARMONI |
| Potential Gap | Possible unresolved issue |

# Literature Clusters

Papers will eventually be grouped into conceptual clusters.

## Cluster A — Human–Automation Interaction

Questions:

- How do humans interact with automation?
- How does automation change human decision-making?
- What causes misuse or disuse of automation?
- What factors influence human reliance?

---

## Cluster B — Situation Awareness

Questions:

- How is situation awareness defined?
- How is situation awareness measured?
- How does automation influence situation awareness?
- Can interface design improve situation awareness?

---

## Cluster C — Trust and Reliance

Questions:

- What influences trust in automation?
- Is higher trust always desirable?
- How does trust relate to reliance?
- How can inappropriate reliance be detected?

---

## Cluster D — Mental Workload

Questions:

- How does automation influence workload?
- Does additional information reduce or increase workload?
- Which workload measurement techniques are commonly used?

---

## Cluster E — Automation Transparency

Questions:

- What information should automation communicate?
- Does transparency improve understanding?
- Can excessive transparency increase workload?
- What forms of system information are most useful?

---

## Cluster F — Explainable Automation

Questions:

- What makes an explanation useful?
- When should an automated system explain itself?
- What information should an explanation contain?
- Do explanations improve human performance?

---

## Cluster G — Automated Driving

Questions:

- How do drivers interact with Level-2 automation?
- What happens during automation-critical events?
- How are intervention behaviours measured?
- What role does interface design play?

---

# Evidence Quality

Not all papers will receive equal weight.

Priority should generally be given to:

### High Priority

- Peer-reviewed empirical studies
- Strong experimental methodology
- Relevant participant population
- Clear operationalization of variables
- Reproducible methodology

### Medium Priority

- Peer-reviewed theoretical papers
- Systematic reviews
- Meta-analyses
- Established conceptual frameworks

### Supporting

- University publications
- Research reports
- Technical standards
- Conference materials

---

# Important Rule

A paper should never be included merely because its conclusion supports HARMONI.

Contradictory or negative findings are equally valuable.

The purpose of this matrix is to understand the research landscape objectively.
