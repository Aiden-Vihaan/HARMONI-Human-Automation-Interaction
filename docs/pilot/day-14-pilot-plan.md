# HARMONI — Day 14 Pilot Plan

## Objective

The pilot will validate the experimental procedure before the main study.

---

## Pilot Objectives

1. Validate technical reliability.
2. Validate participant comprehension.
3. Validate communication-condition differentiation.
4. Validate Situation Awareness questions.
5. Validate workload measurement.
6. Identify learning effects.
7. Identify ceiling or floor effects.
8. Verify event logging.

---

## Pilot Procedure

CONSENT
    ↓
TASK INSTRUCTIONS
    ↓
PRACTICE TRIAL
    ↓
EXPERIMENTAL TRIALS
    ↓
SA QUESTIONS
    ↓
WORKLOAD ASSESSMENT
    ↓
MANIPULATION CHECK
    ↓
DEBRIEF
    ↓
DATA AUDIT

---

## Technical Checks

Verify:

- Trial assignment
- Condition randomisation
- Event timestamps
- Response timestamps
- Reaction-time calculation
- Decision logging
- Missing data
- Session completion

---

## Human Factors Checks

Evaluate:

- Task comprehension
- Message readability
- Perceived information differences
- Response confidence
- Situation Awareness question comprehension
- Workload assessment burden

---

## Manipulation Check

Participants should perceive an information progression:

C1 → Low information

C2 → Moderate information

C3 → High information

The conditions should not primarily be perceived as differences in urgency.

---

## Pilot Revision Rules

Any modification resulting from pilot testing must be documented.

Changes must include:

- Date
- Problem identified
- Evidence
- Design decision
- Reason for change
- Version number

---

## Pilot Exclusions

Pilot data will not be used to:

- Search for statistical significance
- Select favourable participants
- Remove inconvenient observations
- Confirm the final hypothesis
- Report final experimental effects

---

## Pilot Deliverables

The pilot should produce:

1. Stable prototype
2. Validated trial sequence
3. Validated data schema
4. Documented methodological changes
5. Readiness decision for the main study
