## Experimental Data Flow

---

# 1. Overview

The data flow follows:

Scenario Configuration
        ↓
Trial Initialisation
        ↓
Condition Assignment
        ↓
Scenario Execution
        ↓
System Events
        ↓
Participant Events
        ↓
Assessment Responses
        ↓
Raw Event Dataset
        ↓
Trial-Level Dataset
        ↓
Derived Metrics
        ↓
Statistical Analysis
