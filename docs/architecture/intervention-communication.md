# HARMONI — Day 28
## Intervention Communication & Participant Response Layer

Project: HARMONI
Phase: Human-System Interaction
Day: 28
Status: In Progress

---

# 1. Purpose

Day 28 introduces an explicit intervention communication layer.

The system must distinguish between three separate concepts:

1. The automated system decides that intervention is required.
2. The participant is presented with an intervention request.
3. The participant acknowledges and responds to the request.

These are not the same event.

---

# 2. Core Principle

The experimental system should distinguish:

SYSTEM DECISION
      ↓
INTERVENTION REQUEST
      ↓
PARTICIPANT PERCEPTION
      ↓
PARTICIPANT ACTION
      ↓
SYSTEM ACKNOWLEDGEMENT
