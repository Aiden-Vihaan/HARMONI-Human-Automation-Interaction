# HARMONI — Project Scope

## Project Scope

HARMONI is a six-week Human Factors research project combining:

- Human–Machine Interaction
- Human Factors
- UX research
- Experimental design
- Interactive software development
- Data analysis

---

# Included

## Research

- Literature review
- Research-gap analysis
- Research questions
- Hypotheses
- Experimental methodology
- Human Factors interpretation

## User Research

- Participant recruitment
- Exploratory interviews/surveys where appropriate
- User needs
- Human Factors requirements
- Pilot testing

## Design

- Automation-state model
- Information architecture
- Interface design
- Interaction design
- Two experimental interface conditions

## Engineering

- Browser-based simulation
- Scenario engine
- Automation-state engine
- Event logging
- Data export

## Experiment

- Pilot study
- Exploratory participant study
- Behavioural measurements
- Subjective measurements

## Analysis

- Data cleaning
- Descriptive statistics
- Appropriate statistical testing
- Effect-size analysis where appropriate
- Data visualisation
- Human Factors interpretation

## Communication

- Research paper
- Research poster
- GitHub documentation
- Portfolio case study
- Demonstration video

---

# Not Included

HARMONI will not attempt to develop:

- Real autonomous-driving algorithms
- Computer vision
- Object detection
- Autonomous navigation
- Path planning
- Vehicle control
- Real vehicle hardware
- Production ADAS
- Real-world vehicle testing
- Full physics-based driving simulation
- Commercial automotive software

---

# Scope Principle

The project will prioritize **experimental validity and Human Factors depth over technical feature quantity**.

A feature will only be implemented if it contributes meaningfully to:

1. The research question
2. The experimental design
3. The human interaction being studied
4. The validity of the collected data

---

# Six-Week Constraint

The project is intentionally scoped to produce a credible research prototype within approximately 42 days.

If scope expansion becomes necessary, research validity and experimental quality will take priority over additional visual or technical features.
